# Original Unreal source boundary

`Source/` contains the original UEGT Unreal implementation and is licensed under the MIT license in this directory.

The GPL OpenXcom tree elsewhere in this repository is reference material and is not compiled, included, linked, or loaded by the Unreal targets. Production code must not include OpenXcom headers, link its objects or libraries, copy its implementation, embed its standard data, or reproduce its protected audiovisual content.

Functional coverage is tracked at the game-system level so the final game retains the requested strategic and tactical breadth. Rules, presentation, data formats, names, narrative, art, audio, and implementation are original UEGT work.
